# Little Learners World

A beginner-friendly, static website for early-learning activities. It uses only HTML, CSS, and JavaScript, so there is no build step, server, or paid dependency.

## Files
- `index.html` — complete website with homepage, interactive ABC / counting / color-and-shape games, and a printable worksheet.

## Preview locally
Open `index.html` in a modern web browser.

## Publish for free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new **public** repository, for example `little-learners-world`.
3. Upload `index.html` to the repository's top level (root).
4. Open the repository's **Settings → Pages**.
5. Under build/deployment, select **Deploy from a branch**.
6. Choose the `main` branch and `/(root)`, then save.
7. Wait for GitHub Pages to publish and follow the website link shown in Settings → Pages.

The site is static and can be hosted on other free static hosting services too. You do not need to purchase a domain; the host provides a URL.

## Before sharing widely
- Test on a phone, tablet, and desktop.
- Review all content for your intended audience.
- This starter site does not collect personal information, create accounts, or process payments.
- If you later add analytics, advertising, accounts, forms, or payments, update the privacy notice and follow applicable privacy rules and the host/platform policies, especially because the audience includes children.
- Hosting is free within the host's current plan and terms; terms can change.
